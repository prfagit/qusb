FIRST RUN (once, on a machine you trust, ideally offline)
---------------------------------------------------------
Open a terminal in this stick's folder, then run the line for your OS.
<STICK> is this stick's mount path.

  macOS (Apple silicon)   bin/qusb-macos-arm64 init <STICK>
  macOS (Intel)           bin/qusb-macos-x64 init <STICK>
  Linux (x64)             bin/qusb-linux-x64 init <STICK>
  Linux (arm64)           bin/qusb-linux-arm64 init <STICK>
  Windows (x64)           bin\qusb-windows-x64.exe init <STICK>

macOS/Linux may need: chmod +x bin/qusb-*
Check the binaries first:  bin/qusb-<os> verify
